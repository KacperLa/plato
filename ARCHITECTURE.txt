Update Mode Mapping (Waveshare):
================================

Plato UpdateMode          IT8951 Mode     Characteristics
─────────────────────────────────────────────────────────
UpdateMode::Gui       →   GC16 (mode 2)   Best quality, 16 levels
UpdateMode::Partial   →   GL16 (mode 3)   Good quality, faster
UpdateMode::Full      →   GC16 (mode 2)   Full refresh, ghosting removal
UpdateMode::Fast      →   DU (mode 1)     Fast, 1-bit monochrome
UpdateMode::FastMono  →   A2 (mode 6)     Fastest, animation mode


Data Flow for Display Update:
==============================

1. Application renders content
   ↓
2. Calls fb.update(rect, mode)
   ↓
3. WaveshareFramebuffer::update()
   │
   ├─→ write_to_device(rect)
   │   ├─→ mmap /dev/fb0
   │   ├─→ copy local buffer to device
   │   └─→ munmap
   │
   └─→ refresh_display(rect, mode)
       └─→ IT8951 controller updates e-ink panel

─────────────────────               ──────────────

   │                                   │
   ├─ rustup target add                ├─ apt-get install deps
   │  aarch64-unknown-linux-gnu        ├─ configure framebuffer
   │                                   ├─ set environment vars
   ├─ cargo build --target=...         └─ install systemd service
   │  └─ Cross-compile                     (optional)
   │
   └─ Binary: target/.../plato      5. sudo ./plato
                                       │
2. ./deploy-rpi4.sh                    ├─ Detect Raspberry Pi
   │                                   ├─ Load WaveshareFramebuffer
   ├─ scp plato → pi@rpi:/plato       ├─ Initialize display
   ├─ scp resources                    ├─ Start event loop
   └─ scp settings                     └─ Render UI
      │
      ↓
3. SSH connection established
